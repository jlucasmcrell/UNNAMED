4. HOW A NEW ASSET GETS BOUND
------------------------------------------------------------------------------------------------
  4.1 Resolution (ArtLibrary.cs)
    - Static model:   <root>\ready\<id>\<id>.glb            (ArtLibrary.Model / ModelWithLods)
    - Lighter levels: <root>\ready\<id>\<id>_lod1.glb .. _lod3.glb (max 3). The chain stops at the first missing level or the
                      first level whose surfaces lack the full model's textures (it would draw white).
    - Skinned model:  <root>\rigged\<id>\<id>_rigged.glb      (people, creatures)
    - Clip:           <root>\animation\ready\<family>\anim.<clip_id>.glb + record <root>\animation\clips\anim.<clip_id>.json
                      (loop, duration_s, events; source block). Family folders: player, npc, humanoid, creatures.
    - World material: <root>\materials\<id>\<id>_material.json + maps named in its "maps" (basecolor, normal, orm[, ao, roughness]).
    - Every relative path is looked up in primary first, then fallback, PER FILE. Consequence: replacing only <id>.glb in primary while
      fallback still holds <id>_lod1-3.glb mixes your new LOD0 with the old depot LODs ("partial override", printed at load). Ship all
      levels in primary, or none, or delete/rename the depot levels.
    - An id listed in art_bindings.json "withheld" is never drawn (grey box). A missing/broken file is reported, never repaired.
    - textures=cache: texture_cache\manifest.json maps each source (size + hash of first/last 64 KB) to a BC7 .dds. A new or changed file
      simply misses the cache and loads raw (uncompressed RGBA8 - watch VRAM for 4K sets). To compress, run an EDITOR build with
      --texture-cache once; the exported game only reads the cache.

  4.2 Which file to edit (no rebuild needed unless marked)
    - Region bindings overlay: content\_art_bindings.json (also keep UNNAMED\content\_art_bindings.json in sync; identical today).
        structures.<blocker_id>.model            one structure (exact blocker id from content\regions\starting_frontier.yaml)
        structure_prefixes.<prefix>.models[]     every blocker whose id starts with prefix; variant picked by id hash; "wind" stiffness
        building_walls.<prefix>.model            gathers the prefix's wall runs into ONE building model over their footprint;
                                                 interior_light{at,colour,energy,range,shadows,size,fog_energy}, emitters[{recipe,at}]
        doors.<door_id>.model, nodes.<id>.{model,spent}, containers.<id>.{model,sound|hidden}, weapons.<item>.{model,family,hand}
        people.<id>.{model,hand,off_hand,grip,clips{state:clip_id}} and people_by_visual_option["people=production"] (this block wins
          under the launchers), people_clips_by_visual_option["clips=ext"|"people=production"]
        terrain.<cell> (ground identity for scatter/audio), cliffs, materials (record only), models (record only)
        Optional per placement: material (sound/impact family), surface + surface_tint (wear a world material over the model's relief),
          fit:"tile" (repeat a modular piece at its own length), yaw_spread.
    - Shared bindings res://Art/art_bindings.json: creatures, icons, effects, audio, projectiles, ground_item, companion_weapon,
      stations, pieces, withheld. Edit src\Presentation\Art\art_bindings.json and REBUILD/EXPORT the exe - or override the same key
      in content\_art_bindings.json (the merge is recursive, overlay wins), which needs no rebuild.
    - Scatter (grass/flowers/ground cover): content\_scatter_rules.json kinds.<kind>.mesh = "model:<id>" (or a built-in procedural
      mesh name), per_m2 by ground material, fade_m, only_when{plants}. Each kind's LODs are drawn as MultiMesh by distance.
    - Set dressing (scenery, no collider): primary\dressing.json places[{model, at[x,z], yaw}].
    - Terrain textures (Terrain3D): primary\terrain_layers.json [{id, uv_scale, tint}] = material ids under materials\; slot order is
      the layer index used by primary\terrain_cells.json (base, patch, mix_lo/mix_hi, canopy, canopy_scale per cell).
    - Sky: Sky3D under sky=sky3d (addon assets inside the exe); primary\sky.json {"hdri": "sky/<file>.hdr"} only for sky=hdri.
      Atmosphere/fog: primary\atmosphere.json.
    - Audio: primary\manifests\playable_prototype_audio_v3.json sounds[{audio_id, delivered:"audio/v3_delivered/<id>.wav", channels,
      loop, group}]; families are ids minus a trailing .NN (variants picked at random). Environmental hooks: res://Art/audio_hooks.json
      (in exe). Per-cell beds: bindings audio.cells. --visual audio=proof plays <root>\audio_proof\<id>.wav over V3 where present.
    - UI icons: primary\manifests\ui_icons.json icons.<ui.id>.{sprite (128 px shipped), master (256 px)} + ui\icons\ui_icon_atlas.png
      (6x8 cells of 128 px). Fonts: src\Presentation\Ui\Fonts (in exe).
    - VFX: primary\vfx\<name>.png (+ <name>.json provenance) referenced by res://Art/vfx_recipes.json (texture, grid, frames, fps)
      and manifests\magic_vfx.json (atlas, cell_px, grid).

  4.3 _meta.json (pipeline record, NOT read by the game at run time - ArtLibrary only opens the GLB; keep it for provenance tooling
      such as tools/asset_pipeline/cairnwold/check_metas.py). Fields used across the library:
      asset_id, name, category, brief, status ("export_ready"), region/built_for,
      source / source_url / pack / source_depot_folder / author, licence|license, licence_evidence, modification,
      generator{script, script_sha256} | method | generation_model (+ concept_path, raw_3d_path for AI assets),
      convention{frame, units, source}, target_size_m,
      transform{min[3], max[3], dimensions_m{x,y,z} | dimensions[3], origin_mode | glb_origin, glb_up_axis, glb_forward_axis, rescaled_by},
      triangles, base{vertices, faces, triangles, uv_layers, materials[]}, lods{<id>_lodN:{triangles..}} | lods[], lod_status, lod_policy,
      materials / material_slots / material_ids, textures (resolution note), sockets[], nodes[],
      collision{mode:"box", box_dimensions_m[3]} | collision_status + collision_note, rigged, tile_length_m, door_openings,
      gates{...}, verified_by, visual_review, note.
      Minimal useful record for a new asset: asset_id, category, source, source_url, licence, licence_evidence, triangles,
      transform{min,max,dimensions_m,origin_mode}, lods[{level,triangles}], textures, convention, collision{mode,box_dimensions_m}.
      World materials: <id>_material.json {asset_id, material_class, tile_size_m, resolution, maps{basecolor,normal,orm},
      pbr{roughness_base, metallic, normal_strength}, tileable} + <id>_provenance.json {source, source_asset, source_url, licence}.
      Clip records: anim.<id>.json {schema_version, animation_id, skeleton_family, category, animation_family, clip_type, loop,
      root_motion, duration_s, events[], hand_profile, tags[], source{kind, pack, author, license, url, file, sha256}}.

  4.4 Scale, units, pivot
    - glTF binary (.glb), metres, 1 unit = 1 m, transforms applied, no residual node scale/rotation, +Y up, forward -Z (props/rocks;
      building records state +Z as their door face), origin = footprint centre on the ground plane (min Y = 0). Exceptions authored
      on purpose (e.g. cw_lantern_post origin at the post foot) must be reflected in emitter/light offsets, which are in the model's
      own metres.
    - Models are drawn at AUTHORED size - nothing is rescaled (Fitting.cs). Fitting centres the model on its blocker, lays its long
      side along the blocker's, stands it on the terrain, and REJECTS it (grey box + report) if it leaves more than 0.5 m of gap per
      side (1.0 m total per axis) or stops more than 0.6 m below the blocker height. Overhangs: thickness within -0.15/+0.3 m.
      So a replacement must match the blocker footprint (box_m / circle_m + height_m in starting_frontier.yaml) within those margins.
    - Trees: LOD switch 0/35/80/150 m (IsTreeFamily by name); others 0 / max(8,4s) / max(20,10s) / max(45,22s) m (s = largest extent).
      Hard switch (no dither). LOD3 of trees is a crossed-plane impostor (_procgen_tree_lods.py).
    - Materials: alpha-scissor foliage works; baked AO is suppressed for ids in res://Art/ao_flagged.json (near-black AO islands).
    - Weapons: held by their own SOCK_grip_primary empty (+X primary axis). People: hand bone hand.R / hand.L (MPFB) or SOCK_hand.R/.L,
      optional grip{at,primary,secondary} in bindings. Clips are retargeted per skeleton family; the current humans are MPFB
      57-58-joint skeletons and creature rigs are per-species (heat-envelope / rigid-segments).
    - Skin: CharacterMaterials.cs + res://Art/character_materials.json apply per-zone specular/SSS/rim by material-name suffix or the
      explicit material_kinds map; HumanSkin.cs swaps skin to the HumanShaders shader. New characters should keep MPFB-style
      material names (Human_skin / *.body / *.head, hair, eye) or be added to material_kinds.

  4.5 Collision expectations
    - Collision is NOT taken from the asset. The body collides with the simulation's blockers (box/cylinder from the region YAML);
      the drawn model gets the blocker's greybox StaticBody re-parented under it as the camera collider (HollowView.cs:401-409).
      Ship no collision meshes (_collision_* files are never read). The terrain gets a trimesh collider from its own mesh.
    - Scatter and dressing.json placements never collide. Buildings: walls stay as invisible colliders; door openings must line up
      with the wall runs' door gaps in the region YAML (record door_opening in the meta).
