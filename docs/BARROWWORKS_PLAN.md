# Barrowworks implementation map

The Barrowworks (M8) is in every run. `--visual barrowworks=0` is a debug switch that registers no portal, so the frontier
plays as it did before the ring. Save schema is unchanged by the ring (it uses the schema-30 space fields).

## Content and tooling

`tools/gen_barrowworks_blockout.py` owns the room footprints, passages, three gates, readings, archive supplies and headworks
controls in `content/regions/barrowworks.yaml`. Room IDs R01-R13 are stable. The frontier's two portal definitions own their
exterior anchors and offer-readiness flag. The E1-E4 encounter spawns and the Custodian live in `content/spawns/barrowworks/`.

`tools/gen_barrowworks_bindings.py` owns the interior art overlay. The Blender build scripts (`build_barrowworks_rooms.py`,
`_props.py`, `_custodian.py`, `_paper.py`) export the ring's models from licensed sources in the external depot at source
texture resolution; `manifest_barrowworks_assets.py` records them and the native scene cache. `package_barrowworks_assets.ps1`
copies the ring's runtime assets into a playtest package. `tools/plot_barrowworks_kinematics.py` plots collision-fill CSVs.
