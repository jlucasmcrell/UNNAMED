# Native MetaHuman playtest pipeline

Branch `playtest/mh-characters` starts at frozen RC d `4c6bbe11` and includes the approved slice `59aa190e`. Licensed/generated assets stay outside Git. The frozen package is read-only.

The runtime bundle is selected by `OTHERREACH_MH_CHARACTERS_ROOT`, or `mh_characters` next to the executable. `catalog.json` names separate native body/head GLBs, native DCC map folders, native eye/groom manifests, outfit configuration and one baked Hidden Face Map per character/outfit combination. Players remain at full native LOD; NPC LOD selection must be recorded by the native export job and the GLB audit. Missing required meshes, textures, masks or named garment binds fail the character load.

All UE jobs use the original slice project and real RHI under `C:/Otherreach_Recovery/gpu_lock.ps1`, with owner-playing cancellation and a 60-second cooldown after release. Run small batches; do not hold the GPU while queued work waits. Never use NullRHI for these jobs.

1. `probe_npc_sources.py`: read native presets and LOD counts.
2. `prepare_npcs.py`: duplicate ten fresh Epic presets into `/Game/MHPlaytest/NPC`, set native Body Params and 4K source resolutions, and choose native grooms. Age descriptions are selection intent until visual review.
3. `cloud_export_npcs.py`: native Full Rig, 4K source request, separate head/body plus Full Body utility, DCC/DNA and Materials Export. Environment `OTHERREACH_MH_NPC_START` and `OTHERREACH_MH_NPC_COUNT` select a small checkpointed batch.
4. `assemble_npcs.py`: native UE Optimized assembly for semantic face materials and conformed groom cards. Export native lower LODs; do not decimate or prune joints. `audit_glb.py` distinguishes the complete exported reference skeleton from actually weighted joints and counts all influence sets.
5. Stage the runtime catalog and native exports. Run `bake_posed_hidden_maps.gd` with a real renderer and `OTHERREACH_MH_BAKE_MASKS=0`: temporary garment-only GPU pose readbacks and bounded normal segments classify covered body triangle UVs, while native body resources/raw buffers remain byte-identical. `raster_hidden_face_maps.py` creates 2048px mask textures. Body UVs use a repeating native tile; the shader samples the mask with `fract(UV)` without changing mesh UVs. The legacy `OTHERREACH_MH_BAKE_MASKS=1` headless classification is preparation only; never overwrite final posed masks with it.
6. Run the same regression with baking disabled. It checks exact native body mesh/array preservation, garment named binds and LeaderPose. No body ArrayMesh rebuild, rig merge, rebind, rest fixer or body modifier occurs here.

The NPC source/export jobs are preparations, not acceptance. Complete the normal-game creator, NPC and animation checks; measure at the owner's settings; export a committed revision only with `tools/export_playtest_clean.ps1`; launch the package via its actual desktop launcher and capture G4 evidence. The owner approves the result.

The wardrobe plan accepts DevonLux shirt/vest/trousers/hood, with tint and part variants. Rejected boots/gloves are excluded. Claude's body-shell footwear is a separate handoff; bare hands/feet are allowed until it is accepted. Codex owns UE IK Retargeter animation after the NPC exports; the failed DeepSeek custom retarget library is excluded. Until the native UE library passes its source-frame comparison the figure holds its imported base pose and reports idle pending; it does not synthesize locomotion.

NPC faces use the fixed nine-surface table from ibrews/MetaHumanGodot `release.gd` (`PROFILES.her`): skin, teeth, hide, eyeR, eyeL, hide, hide, skin, lashes. Blender applies only those material assignments before export so duplicate native `M_Hide` material slots cannot combine mouth and scalp. The catalog records the table and the runtime assigns shader roles by index. Body/head vertices, weights, native bone hierarchy and rest remain unchanged.

Accepted body-shell footwear: source report `REPORT_FOR_CLAUDE_BODYSHELL_FOOTWEAR.md`; `export_shells_all_weights.py` exports the accepted Ada/Mateo garment objects with all influences. `build_npc_shells.py` runs the accepted shell construction on each NPC's own native reduced body. Only garment objects receive triangulation for tangent export. No derived body is exported or staged; masks hide covered hands and feet. Shells lift the presentation root by 10.5mm for the sole.

`stage_npc_recolours.py` stages DeepSeek's corrected offline garment albedos, retaining author texture detail with distinct linen, leather and wool colours; author normal maps remain. Player materials remain the accepted pair's materials. Replacement body-shell trousers are a separate pending Claude handoff; the first animated DevonLux trousers are rejected for visible artefacts.

Animation route: `prepare_ue_animation_sources.py` imports original UAL1/UAL2 and KayKit GLBs through native UE AssetImportTask. `retarget_native_animations.py` uses Epic IK Rigs, IK Retargeter auto alignment and batch retargeting for each character's own native proportions, then native GLTFExporter with the same body LOD. Quaternius uses Epic's recognized Mannequin chains; KayKit's different 23-joint source uses documented explicit IK chain definitions. No source or target skeleton/rest changes occur. `clean_native_animations.py` uses the same standard Blender glTF bridge as the bodies, retaining all 342 joints. `build_native_animation_library.gd` requires exact native bone names/parents/rests before rebinding track paths, pins the body's SHA256, and measures planted-foot gait pace. Godot performs playback only. `capture_animation_gate.gd` records native/source poses at identical seconds, with full-body, shoulder and hip views. Actual normal-game packaged capture remains required separately.

Epic documentation: [IK Retargeter Python API](https://dev.epicgames.com/documentation/unreal-engine/using-python-to-create-and-edit-ik-retargeter-assets-in-unreal-engine?lang=en-US), [custom MetaHuman IK Retargeter](https://dev.epicgames.com/documentation/en-us/metahuman/create-a-custom-ik-retargeter). UE5.8 public engine headers and runtime Python docs are the version-specific API authority.

UE5.8 root-motion correction: the migrated stock MetaHuman IK Rig exposes pelvis as both retarget pelvis and root-motion bone. Duplicate source/target rigs must call `set_root_motion_bone('root')` and keep the retarget pelvis unchanged, then initialize the default retarget ops. Without this, the exported pelvis collapses to ground level although upper-body poses broadly match. The default scripts now use `ue_native_animations_rootfix.json` and `/Game/MHPlaytest/RetargetRootFix`; the original manifest is obsolete diagnostic evidence. The regression independently samples idle pelvis height. No native skeleton, body, rest or inverse bind changed. [Epic Set Root Motion Bone](https://dev.epicgames.com/documentation/unreal-engine/BlueprintAPI/IKRig/SetRootMotionBone?lang=en-US).

The generalized Claude trouser candidate is staged per own native body via `build_native_trousers.py` and `stage_native_trousers.py`, all influence sets and garment tangents retained. Its pinned source hash and report status are recorded per character; the report's trouser section is still pending. Poly Haven `poly_wool_herringbone` albedo/normal maps are CC0. `trousers_path` chooses this garment; final posed masks must be rebaked and rasterized after changing it. Source body buffers are never rebuilt. Candidate acceptance requires dressed motion and packaged close-up review.

Release decision: run stage_release_wardrobe.py. Ship DevonLux trousers with body-shell boots/gloves; the trouser shell candidate is deferred after torn crotch triangles in actual motion. Supplied VARIANTS_FOR_CODEX.json controls NPC hood/vest choices and source garment recolours. run_dressed_release_gates.ps1 refreshes posed masks, reruns native regression, and captures all26 clips for both players (228 frames). The desktop launcher permits OTHERREACH_MH_REVIEW_HOUR=12 for the requested daylight review, retaining all owner render settings.
