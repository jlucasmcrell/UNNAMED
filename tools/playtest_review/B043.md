# B-043 creator regression

Base: `origin/rc/playtest-2-next` at `aeba2f8c`.

The real card bug reproduces on this base with the accepted Playtest 2 AssetBase.
`CreatorScreen.ShowBody` memoized face, height and sliders but omitted the modular
part IDs. Choosing a hair card changed `Draft.Appearance.Hair` while leaving that
key unchanged, so `CreatorPreview.Look` never applied it. The key now includes
hair, facial hair, outfit and footwear. There is no material, LOD or visibility
override.

The stock `--creator-shots` had a separate stale path: its named bun/ponytail
frames wrote the legacy baked-style slider, which native HumGen bodies do not
consume. It now selects native part IDs and native colour controls on native
bodies, retaining the baked path for baked bodies.

`hair_cards.gd` clicks the actual six long-hair buttons on each Veth body and
checks that each expected hair mesh is attached and visible. It writes sixteen
original renders plus material/mesh audits (six choices and two face views per
body). It exits with error if a selected part is not drawn. `--headless` tests
attachment only and deliberately does not produce visual evidence.

Run with the repository's Godot Mono binary from this worktree, using the normal
content and accepted AssetBase flags. Set `B043_OUT` to a private output directory
and pass `--script ../../tools/playtest_review/hair_cards.gd` before `--`, then
`--b043-review` after `--`. The script opens New Game through the title's real
handler; it does not alter a player profile. Native rendering requires the shared
GPU lease; use a lease of at most ten minutes and release it in `finally`.

The original 66ca5630 capture used older office-new-intern garments and neck masks.
The accepted AssetBase already contains B-020's corrected garments/masks on both
bodies. Keep those accepted art payloads; this change does not alter or republish
owned art. Visual review must include both face views with that exact package.

All image evidence remains outside the public repository. Claude owns the visual
verdict; the integrator owns the RC merge.
